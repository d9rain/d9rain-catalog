# D9rain — каталог в Telegram без своего сервера

Мини-приложение для канала D9rain: каталог вещей в наличии с поиском, фильтром по типу и размеру,
избранным, вкладкой «Инфо» и разделом «Управление» для владельца.

Всё работает бесплатно на GitHub:

- **сайт** лежит на GitHub Pages;
- **новые посты** с #ВНАЛИЧИИ и замену на #ПРОДАНО раз в 15 минут подтягивает планировщик GitHub Actions;
- **правки из «Управления»** сохраняются прямо в репозиторий с вашего телефона.

В каталоге уже 146 вещей из выгрузки канала со всеми фото.

## Запуск: 7 шагов, около получаса

### 1. Бот

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и адрес бота.
2. Сохраните **токен** (строка вида `123456:ABC...`). Никому его не показывайте.
3. Добавьте бота **администратором** в канал @d9rain. Особые права не нужны — он должен
   быть администратором, чтобы видеть новые посты.

### 2. Аккаунт и репозиторий на GitHub

1. Зарегистрируйтесь на https://github.com (бесплатно, нужна только почта).
2. Нажмите **New repository** (зелёная кнопка или «+» вверху).
3. Название — например `d9rain`. Тип — **Public** (обязательно: бесплатный сайт бывает только у открытых репозиториев).
4. Галочки ниже не ставьте → **Create repository**.

### 3. Загрузить файлы

Файлов много (около 900), поэтому через сайт неудобно — проще программой **GitHub Desktop**:

1. Скачайте https://desktop.github.com и войдите в свой аккаунт GitHub.
2. **File → Clone repository** → выберите `d9rain` → **Clone**. Появится пустая папка на компьютере.
3. Распакуйте архив и скопируйте **всё содержимое** папки `d9rain-pages` в эту папку
   (вместе со скрытой папкой `.github` — в Windows включите «Показывать скрытые элементы»).
4. В GitHub Desktop внизу слева напишите любое описание, например «Каталог», → **Commit to main** → **Push origin**.

### 4. Токен бота

На странице репозитория: **Settings → Secrets and variables → Actions → New repository secret**.

- Name: `BOT_TOKEN`
- Secret: токен бота из шага 1

### 5. Включить сайт

1. **Settings → Pages** → в поле **Source** выберите **GitHub Actions**.
2. Вкладка **Actions** → если просит, нажмите кнопку включения workflows.
3. Слева выберите **Каталог** → справа **Run workflow** → **Run workflow**.
4. Через 1–2 минуты появится зелёная галочка. Сайт будет по адресу
   `https://ВАШ-ЛОГИН.github.io/d9rain/` — откройте его в браузере, каталог должен загрузиться.

После этого у бота сама появится кнопка **«Каталог»** слева от поля ввода — это и есть мини-приложение.

### 6. Мини-приложение в Telegram

1. В @BotFather: `/mybots` → ваш бот → **Bot Settings → Configure Mini App** (может называться «Mini App»)
   → включите и вставьте адрес сайта из шага 5.
2. Теперь каталог открывается ссылкой `https://t.me/ИМЯ_БОТА?startapp` — опубликуйте её в канале и закрепите.
3. Ссылка `https://t.me/ИМЯ_БОТА?startapp=item_НОМЕР` сразу открывает конкретную вещь
   (номер — это номер поста в канале).

### 7. Вход в «Управление»

Чтобы править каталог с телефона, приложению нужен ваш ключ GitHub:

1. GitHub → аватарка справа вверху → **Settings → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate new token**.
2. Название любое. **Expiration** — максимальный срок из предложенных.
3. **Repository access → Only select repositories** → выберите `d9rain`.
4. **Permissions → Repository permissions → Contents → Read and write**.
5. **Generate token** и скопируйте ключ (`github_pat_...`).
6. Откройте каталог в Telegram → вкладка **«Инфо»** → внизу **«Вход для владельца»** → вставьте ключ → **Войти**.

Появится вкладка **«Управление»**. Ключ хранится только в вашем Telegram и даёт доступ только к этому репозиторию.
Когда срок ключа истечёт, приложение попросит новый — повторите пункты 1–6.

**Уведомления (по желанию).** Напишите боту `/id` — в течение 15 минут он ответит вашим ID.
Впишите его в **Settings → Secrets and variables → Actions → Variables → New repository variable**:
Name `ADMIN_IDS`, Value — ваш ID. Бот будет писать вам «Добавил в каталог: …» и «Снял с продажи: …».

## Как пользоваться

**Новая вещь.** Опубликуйте пост с фото и хэштегом #ВНАЛИЧИИ — в течение 15–30 минут вещь появится в каталоге
со всеми фото. Название берётся из первой строки, размер, состояние и цена — из строк «Размер», «Состояние», «Цена».

**Продано.** Замените в посте #ВНАЛИЧИИ на #ПРОДАНО — вещь уйдёт из каталога. Либо переключите статус в «Управлении».

**Правки в «Управлении»:** добавить вещь без поста, загрузить и удалить фото, сменить обложку стрелками,
изменить описание и цену, снять с продажи или вернуть, отредактировать текст «Инфо».
Покупатели увидят изменения через 1–2 минуты.

**Если правили текст в «Управлении»,** правки этого поста в канале его больше не перезаписывают
(хэштеги #ВНАЛИЧИИ и #ПРОДАНО продолжают работать).

## Что важно знать

- **Задержки.** Новые посты — до 15–30 минут, иногда дольше: GitHub не гарантирует точное время запуска.
  Ответы бота на `/start` и `/id` тоже приходят с этой задержкой. Ускорить можно кнопкой **Run workflow** во вкладке Actions.
- **Чего бот не видит:** удаление поста в канале; посты, если синхронизация не работала дольше суток.
  Старому посту, которому позже поставили #ВНАЛИЧИИ, подтянется только первое фото — остальные добавьте в «Управлении».
- **Открытый репозиторий.** Код и каталог видны всем, кто найдёт репозиторий, — в том числе скрытые вещи.
  Токен бота и ключ GitHub при этом никто не видит.
- **Если что-то сломалось,** откройте вкладку **Actions**: красный крестик — ошибка, внутри запуска написано, что не так.

```
data/catalog.json                каталог: вещи, текст «Инфо», настройки
data/state.json                  служебное состояние синхронизации
photos/                          фото: export — из выгрузки, thumbs — обложки, items — новые
sync/sync.js                     синхронизация с каналом (запускается GitHub Actions)
sync/parse.js                    разбор текста поста в карточку
.github/workflows/sync.yml       расписание и публикация сайта
```
